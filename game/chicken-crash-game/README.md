## 🚀 አጨዋወትና ማስነሻ (How to Run)

### አማራጭ 2 (በ Terminal / CMD):
```bash
cd c:\Users\HP\Desktop\crash\chicken-crash-game
npm start
# ወይም: node server.js
```

ከዚያ ብራውዘር ላይ `http://localhost:8089` ይክፈቱ።
