# Tower Dash - Organized Assets & Resources

ይህ ፎልደር በሙሉ የጨዋታውን ፋይሎች በየዓይነታቸው ለብቻ ለብቻ ተለይተው የተደራጁበት ማህደር ነው።

## Folder Structure

### 📁 01_Blocks/ (የግንብ ብሎኮች)
እያንዳንዱ ብሎክ በራሱ የተለየ ፎልደር ተቀምጧል:
- `Block_01_Temple/` - የጥንታዊ ቤተ-መንግሥት/ባንክ ቅርፅ ብሎክ (Floor 3)
- `Block_02_TownHouse/` - ሰማያዊ የከተማ ቤት ብሎክ (Floor 4)
- `Block_03_YellowHouse/` - ቢጫ ጡብ ቤት ብሎክ (Floor 5)
- `Block_04_LogCabin/` - የእንጨት ካቢን በክፍት በርና አረንጓዴ ሳር ክዳን (Floor 1)
- `Block_05_Shop/` - አረንጓዴ የሱቅ ፊት ለፊት ብሎክ (Floor 6)
- `Block_06_Skyscraper/` - የፎቅ ሕንፃ ብሎክ (Floor 7)
- `Block_07_Lab/` - የላቦራቶሪ ብሎክ (Floor 8)
- `Block_08_NeonApartment/` - የኒዮን አፓርታማ ብሎክ (Floor 9)
- `Block_09_Penthouse/` - ፔንትሃውስ ብሎክ (Floor 10)
- `Block_10_Container/` - ቀይ የማጓጓዣ ኮንቴይነር በክብ መስኮት (Floor 2)
- `Block_11_AntennaTower/` - የአንቴና ማማ ብሎክ (Floor 11)
- `Block_12_Observatory/` - የጠፈር መመልከቻ/ኦብዘርቫቶሪ ብሎክ (Floor 12)

### 📁 02_Crane_and_Hooks/ (ክሬን እና መንጠቆዎች)
- `kran2.png`, `kran3.png`, `kran4.png` - ክሬን መንጠቆዎች (Hazard striped hooks)
- `line_2.png` - የብረት ማንጠልጠያ ገመድ (Cable line)

### 📁 03_Smoke_and_Effects/ (የጭስና የማረፊያ አኒሜሽን ፍሬሞች)
- `Drop_FX_Smoke/` - ብሎኮች መሬትና እርስ በእርስ ሲያርፉ የሚወጣው 10 ፍሬም የጭስ አኒሜሽን
- `Smoke_FX_1/` - የጭስ ፍንዳታ ፍሬሞች
- `Smoke_FX_2/` - ተጨማሪ የጭስ ፍሬሞች
- `Smoke_FX_Middle/` - የመሃል ጭስ ፍሬሞች

### 📁 04_Scenery_and_Backgrounds/ (የመሬት፣ ከተማና የሰማይ ምስሎች)
- `Ground_and_Pedestal/` - የግንባታው ሜዳ (Yard)፣ አጥር፣ ጋሪዎች እና የድንጋይ መሠረት (Pedestal)
- `City_Backdrops/` - የከተማው ሕንፃዎች ፓኖራማ
- `Sky_and_Clouds/` - ደመናዎች፣ ጋላክሲ፣ ከዋክብት
- `Airplanes_and_Balloons/` - አውሮፕላኖችና ፊኛዎች
- `Creatures_and_Space/` - ጭልፊቶች/ወፎች (Seagulls)፣ ዩፎ (UFO)፣ ስፑትኒክ ሳተላይቶች

### 📁 05_Audio/ (የድምፅ ፋይሎች - 65 Audio Tracks)
- `Music_Layers/` - 4 የመሰረታዊ ጨዋታ የሙዚቃ ቅንብሮች እና የቦነስ ሙዚቃዎች
- `Voice_Lines/` - ገጸ-ባህሪያቱ የሚናገሯቸው ንግግሮች (Welcome, Win, Fail, Move lines)
- `Sound_Effects/` - የመውደቅ (Hit)፣ የመሰበር (Destroy)፣ የገንዘብ ማውጣት (Cashout) ድምፆች

- `Back_Main/` - የጀርባ አኒሜሽን ስፓይን
- `Back_Elements/` - ተንቀሳቃሽ የጀርባ አካላት
- `Win_Celebration/` - የድል ማክበሪያ አኒሜሽን
- `Bonus_Features/` - የቦነስ ካርድና ነፃ ዙር አኒሜሽን
- `UI_and_Icons/` - ሳንቲሞች፣ ቆቦችና ዩአይ አኒሜሽን
