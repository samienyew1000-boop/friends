MULTI HOT 5 - STANDALONE GAME FOLDER
====================================

ይህ ፎልደር ራሱን ችሎ የሚሰራውን የ Multi Hot 5 ጨዋታ ሙሉ ፋይሎች ይዟል።
(This folder contains the complete standalone, production-ready Multi Hot 5 game).

ጨዋታውን ለመጀመር (How to Play):
------------------------------
1. በቀላሉ "Play_Game.bat" ፋይል ላይ Double Click ያድርጉ።
   (Simply double-click "Play_Game.bat").

2. አሳሽዎ (Browser) በራሱ ተከፍቶ ጨዋታውን ያመጣልዎታል።
   (Your default browser will launch automatically with the game running at http://localhost:8080/).

የጨዋታው መቆጣጠሪያዎች (Controls):
------------------------------
- ስፒን ለማድረግ (Spin): Spacebar ይጫኑ ወይም በስተቀኝ ያለውን አረንጓዴ Spin ቁልፍ ይጫኑ።
- ውርርድ ለመቀየር (Bet): + እና - ቁልፎችን ይጠቀሙ።
- ድርብ ጨዋታ (X2 Gamble): አሸናፊ ሲሆኑ በስተግራ ያለውን 2x ቁልፍ በመጫን የቀይ ወይም የጥቁር ካርድ ይገምቱ።
- አውቶስፒን (AutoPlay): በስተግራ ያለውን AutoPlay ቁልፍ ይጫኑ።
- ሜኑ (Menu): በላይኛው ቀኝ በኩል ያለውን ☰ በመጫን የክፍያ ሰንጠረዥ (Paytable)፣ ድምፅ ቅንብሮች (Settings) እና ታሪክ (History) ይመልከቱ።
